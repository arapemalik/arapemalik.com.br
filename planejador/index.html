Planejador

Ferramenta pessoal de planejamento do canal Qual a Ligação?

O Planejador roda no computador do próprio criador do canal. Ele organiza a pauta, o calendário de postagens e as métricas, e usa os Serviços de API do YouTube (YouTube API Services) para:

  • enviar e agendar vídeos no canal do próprio dono, depois de ele aprovar cada postagem;
  • ler as estatísticas desses vídeos, para mostrar o que está funcionando;
  • listar os vídeos em alta por país, como inspiração de pauta.

Não é um serviço aberto ao público: só a conta do dono do canal entra.
