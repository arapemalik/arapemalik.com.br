Privacidade

Planejador · última atualização: 17 de outubro de 2026

Quem usa

O Planejador é uma ferramenta pessoal do criador do canal Qual a Ligação?. Ele roda no computador do próprio criador e só a conta Google dele se conecta. Não há cadastro de outras pessoas.

O que o app usa dos Serviços de API do YouTube

Este app usa os Serviços de API do YouTube (YouTube API Services). Ao conectar a conta, o dono do canal autoriza o app a:

  • enviar vídeos para o canal dele (permissão youtube.upload), sempre depois de ele aprovar;
  • ler dados do canal e dos vídeos (permissão youtube.readonly), como título e lista de vídeos;
  • ler estatísticas (permissão yt-analytics.readonly), como visualizações e tempo assistido.

Também consulta a lista pública de vídeos em alta por país.

Onde os dados ficam

Tudo fica no computador do dono do canal, num banco de dados local. O token de acesso fornecido pelo Google fica num arquivo de configuração local, fora do código. Nada é vendido, compartilhado ou enviado a terceiros. Não há anúncios.

Por quanto tempo

As estatísticas guardadas são atualizadas regularmente e podem ser apagadas a qualquer momento pelo dono do canal. Ao desconectar a conta, o token é apagado do computador.

Como revogar o acesso

A permissão pode ser retirada a qualquer momento emsecurity.google.com/settings/security/permissions.
